# Backups / Sauvegardes

`docker compose run --rm backup` writes database backups here (`orbitos-YYYYMMDD-HHMMSS.dump`).
They contain all your data: keep a copy on another disk or computer, and keep it private.
Restore: see `orbitos/docs/en/install.md`.

`docker compose run --rm backup` écrit ici les sauvegardes de la base de données.
Elles contiennent toutes vos données : gardez-en une copie sur un autre disque ou ordinateur, en lieu sûr.
Restauration : voir `orbitos/docs/fr/install.md`.
