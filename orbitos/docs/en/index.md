# OrbitOS documentation

*[Version française](../fr/index.md)*

OrbitOS is an open-source IoT platform: connect devices, collect their data, see it on dashboards
and act on it with rules. It works in English and French, runs on your own computer or server,
works offline, and sends nothing to anyone.

| Guide | For |
|---|---|
| [Quick start](quick-start.md) | Everyone: from zero to a live dashboard in about 15 minutes |
| [Install, back up, upgrade](install.md) | The person who runs the server |
| [Administrator guide](admin-guide.md) | Daily use: organizations, users, devices, dashboards, alarms, rules |
| [Connect devices](connect-devices.md) | MQTT, HTTP, CoAP, encrypted MQTT, LoRaWAN, Modbus and other industrial protocols |
| [APIs and webhooks](api.md) | Applications that read data or send commands |
| [Privacy and security](privacy-security.md) | Two-factor sign-in, audit log, retention, privacy requests (Law 25, PIPEDA) |
| [Your brand](branding.md) | Name, logo, colors, legal links |
| [Add a language](add-a-language.md) | Translators |
| [Developer guide](developer-guide.md) | Building, testing and changing OrbitOS |

These guides are served by your own server: they work without internet access.
