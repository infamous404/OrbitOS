# IoT Gateway configuration / Configuration de la passerelle IoT

Used only by the optional gateway add-on (`docker compose --profile gateway up -d`).
On first start the gateway copies its default files here; edit them, then `docker compose restart gateway`.
See `orbitos/docs/en/connect-devices.md`.
